> 本文聚焦风电功率预测的各类时间尺度及其具体实现方法，从技术路线、核心算法到工程实践进行全面阐述。

## 1. 风电功率预测概述

### 1.1 风电预测的特殊性

风力发电功率预测的核心难点在于：风速具有高度的波动性和随机性，且受地形、海拔、大气稳定度等多种因素影响。风电机组的输出功率与风速呈非线性关系（风功率曲线），在切入风速与额定风速之间呈三次方关系，在额定风速与切出风速之间趋于恒定，超过切出风速后停机输出为零。随着AI气象大模型（华为盘古、复旦大学伏羲、中国气象局风清、上海AI实验室风乌等）的快速发展，NWP气象预报精度已获得显著提升，但复杂地形下的局地气象特征捕捉和极端天气事件预测仍是当前技术难点。  
**政策背景**：2026年1月，中国气象局、国家能源局联合印发《关于推进能源气象服务体系建设的指导意见》，明确提出到2027年基本建立覆盖全场景和短临至月季年尺度无缝隙的一体化能源气象服务体系。

### 1.2 风电预测的技术体系

风电功率预测采用多学科综合方法，需要掌握：

- 风能资源评估技术
- 气象监测与数值天气预报
- 风力发电功率预测建模
- 预测系统架构与工程部署

预测的通用流程为：**数据整理 → 特征工程 → 模型选择 → 模型训练 → 功率预测**

本文件使用的评价指标、气象源定义、AI大模型详情等参见《新能源预测核心名词解释》（第一篇）第3章、第4章。后续不再重复说明。

## 2. 风电短期功率预测（0~72小时）

### 2.1 定义与要求

- **时间尺度**：未来0~72小时（可延至7~10天）
- **时间分辨率**：15分钟
- **主要用途**：日前发电计划编制、电网调峰、常规机组启停安排、日前市场报价

### 2.2 技术路线（三种模式）

短期预测以电网结构为基础，结合预测目标区域的气候特征及风电场历史数据，根据预测时间尺度和实际应用需求，采用多种预测方法构建特定预测模型，进行全网/区域/单站功率预测，获得最优预测策略。短期预测主要包含三种模式：

1. **子站加和预测**：对子站功率预测模型进行评价，将预测质量较差子站的预测模型进行优化或替换，再将子站的预测值进行加总，获得区域预测功率。
2. **调度侧预测**：根据电网结构和断面限制，结合区域历史出力情况和区域多个典型气象特征预测点，提取数值天气预报，利用基于线性模型、树模型、神经网络等多种模型与框架开发的模型融合功率预测算法，对区域进行预测功率。
3. **单站预测**：基于单站历史数据和气象预报，直接建立预测模型。

### 2.3 核心算法

#### 2.3.1 树模型类算法（主流方法）

**（1）GBDT（梯度提升决策树）**

GBDT全称梯度提升决策树，由梯度下降法、加法模型和前向分布算法构成。在构建决策树过程中，生成弱分类器会产生残差值，梯度下降优化残差值使其最小，得到最好分类效果。残差恰好也是负梯度，因此优化残差等同于优化负梯度。

**（2）XGBoost（极端梯度提升）**

XGBoost在GBDT基础上增加了正则化项，可有效防止过拟合。其独特的block存储结构可以进行形式上的并行操作，加速模型训练。支持自定义损失函数和评估指标。在实际风电短期预测中，XGBoost通常以梯度提升树为基学习器，采用回归目标函数，配合列采样和子采样等正则化手段控制过拟合。**某2025年AI驱动预测框架的比较研究表明，XGBoost在所有评估模型中显示出最高的预测精度（R²达0.9890），优于Transformer变体、Temporal Fusion Transformer等模型。**

**（3）LightGBM（轻量梯度提升机）**

LightGBM采用基于直方图的决策树学习算法，给定一个范围值进行数据分类操作，训练速度更快，内存占用更低。在风电短期预测中为主要模型之一。

主要训练参数包括：树的最大深度、特征比例、迭代数据比例、正则化参数、学习率、叶子数、迭代次数。

典型输入特征：10米高度风速/风向、30米高度风速/风向、50米高度风速/风向、70米高度风速/风向、温度、相对湿度、压强、降水量。

**最新研究趋势**：2026年一项可解释AI增强的能源预测研究表明，LightGBM在5分钟数据聚合成日度间隔的应用中被确定为最有效的学习器，结合SHAP和LIME可解释性分析后，模型预测能力进一步提升。

**（4）CatBoost**

CatBoost在处理类别型特征方面具有优势，使用有序提升（Ordered Boosting）减少过拟合。在实际风电短期预测中，LightGBM与CatBoost通常搭配使用，形成多模型互补组合，前者训练速度快、后者对类别特征处理更优，两者预测结果加权融合以提升整体精度。

#### 2.3.2 深度学习算法

在风电短期预测中，深度学习模型作为重要补充方案，2025–2026年涌现出大量新技术：

| 模型                         | 特点                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| **LSTM**                     | 长短期记忆网络，擅长捕捉时序数据的长期依赖关系，是超短期预测的核心模型 |
| **GRU**                      | 门控循环单元，LSTM的简化版本，训练更快                       |
| **CNN-BiLSTM**               | 卷积双向长短期记忆网络，研究显示CNN-BiLSTM模型在复杂地形短时预测中显著优于传统模型 |
| **TCN**                      | 时间卷积网络，利用因果卷积处理时序问题                       |
| **Transformer**              | 基于自注意力机制，可并行处理序列数据；2026年多项研究探索了Transformer在风电预测中的应用，包括MSTCN-Transformer（多尺度时间卷积Transformer）和Non-stationary GNNCrossformer等变体 |
| **图神经网络**               | GCN/图注意力网络，可建模电站间时空关联关系；2025–2026年出现了IF-ASGAT（自适应稀疏图注意力网络）和STGCN-GA等新结构，后者在RMSE、MAE和R²指标上分别提升23.45%、18.05%和11.51% |
| **FNN**                      | 前馈神经网络，基础深度学习模型                               |
| **CNN-LSTM系列**             | 2026年出现了多种改进版本：NGO-CNN-LSTM-MHA集成模型在海上风电场预测中达到98%准确率和99%合格率；PR-CNN-LSTM（粒子群优化残差结构）扩展了传统架构；CEEMDAN-CNN-BiLSTM结合了信号分解方法 |
| **时间序列基础模型（TSFM）** | 2026年一项实证研究对多种先进Transformer架构和时序基础模型在风电、光伏、负荷预测中的性能进行了系统基准测试，表明基础模型正成为该领域的前沿方向 |

#### 2.3.3 统计学习方法

**（1）多元回归分析**

通过因子分析方法提取电站出力影响要素，建立影响要素与电站发电的映射模型。包括多元线性回归和非线性回归。

**（2）BP神经网络**

人工神经网络是一种仿动物神经网络行为特征进行分布式并行信息处理的数学模型，具有自适应学习能力，适合处理动态、复杂、非线性的数据。

**（3）朴素贝叶斯算法**

基于每个样本的最大似然估计概率、回归估计的联合概率和条件概率进行建模，输入为多高度风速/风向、温度、湿度、压强等特征。

### 2.4 特征工程（分步详解）

风电短期预测的特征工程包含以下关键步骤：

#### 2.4.1 数据整理

- 检测异常值（越限、死值、跳变等），对异常值进行修正和剔除
- 使用实测功率绘制风速-功率散点图，剔除限电数据
- 使用Savitzky-Golay滤波器进行功率数据平滑处理

#### 2.4.2 特征构建

- **时间特征**：年内日序号、小时等
- **风速特征**：风速的二次方（风速²近似反映风功率密度）
- **多高度物理剖面特征**： 
  - **风切变指数**：α = log(u₂/u₁) / log(z₂/z₁)，量化风速随高度的变化率
  - **温度梯度**：表征热力分层状况，影响湍流发展和动量输送
  - **湿度亏缺**：地表相对湿度的补数，反映空气干燥程度及其对空气密度的影响
  - **气压变化率**：指示天气尺度的系统演变
  - **滚动统计量**：24小时滑动均值和标准差，捕捉日循环持续性和中尺度变率
- **多气象源加权融合**：将EC、CMC、DWD、GFS、MF、GEFS、UKMO、JMA等气象源的预报结果进行加权组合，权重通过优化搜索确定（详见6.1节）
- **滞前滞后特征**：对关键气象变量构建shift和gap特征（±1、±3个时间步）
- **分组统计特征**：按日-小时分组计算气象变量的均值、标准差、最大值、最小值
- **滚动窗口特征**：3步滚动均值、最大值及其shift变体

#### 2.4.3 特征选择

- 基于Pearson相关系数的特征筛选
- 基于风速k系数的特征筛选：对每个气象源的风速列，寻找最优系数k使得k×风速与实际功率的MAE最小

### 2.5 模型融合策略（AI大模型+物理模型）

在风电短期预测中，采用**AI大模型+物理模型混合融合**策略：

1. **基础融合**：融合功率由机器学习预测值（权重75%）与物理外推值（权重25%）加权组合而成
2. **AI大模型增强**：引入新能源大模型（如远景“天机”气象大模型、华为盘古大模型等）作为顶层融合层，整合多源数据实现高精度预测
3. **多模型互补**：将不同模型的融合结果按比例组合，例如模型1融合值权重25%、模型2融合值权重75%

通过交叉验证选择最优权重组合，实现多模型互补。**案例**：2025年6月，深圳能源与华为云联合发布基于盘古大模型的新能源功率预测系统，实现中短期风光水电发电量预测，风电功率预测准确率提升10%，气象预测准确率提升15%；系统分辨率最高可达1公里，提供秒级天气预报。2026年最新趋势显示，“AI大模型+物理模型”的混合预测模式能够充分发挥各方法的优势，减少短期及中长期功率预测误差。

## 3. 风电超短期功率预测（0~4小时）

### 3.1 定义与要求

- **预测时间尺度**：未来0~4小时（可延至未来10h超短期预测）
- **时间分辨率**：15分钟，滚动预测
- **主要用途**：实时调度、日内修正、日内市场交易

### 3.2 技术路线

超短期预测基于短期气象预报数据、短期功率预测数据及实发功率数据实现，分两步走：

**第一步**：基于实发功率数据，使用**滑动平均自回归模型（ARMA）**进行简单的超短期预测。

**第二步**：将上述简单预测结果、短期气象预报数据及短期预测功率共同作为模型输入，采用**长短期记忆人工神经网络（LSTM）**实现对未来4~6小时（可延至10小时）的超短期功率预测。

### 3.3 核心算法

#### 3.3.1 逻辑回归算法（LR）

逻辑回归属于线性回归模型，采用sigmoid函数做数据映射，将样本数据映射到(0,1)之间，采用极大似然估计方法找到最大参数Θ，通过梯度上升方法使似然函数最大化。使用交叉熵损失函数将真实值和预测值结合，梯度下降法进行优化。

#### 3.3.2 LSTM网络

长短期记忆网络是超短期预测的核心深度学习模型，其门控机制（遗忘门、输入门、输出门）可以有效捕捉功率变化的时序特征和长期依赖关系，相比传统RNN解决了梯度消失问题。**2025-2026年，CNN-BiLSTM、CEEMDAN-CNN-BiLSTM等多种LSTM变体在短期/超短期预测中展现出更优越的性能。**

### 3.4 气象数据源

超短期预测的气象输入主要来源于：

- 短期NWP预报数据的日内更新（日内气象）
- 测风塔实时气象数据（15分钟更新一次）
- 实发功率数据
- **AI气象大模型实时更新**：随着AI气象大模型（如华为盘古、远景天机）支持分钟级气象数据更新，其高频率、高精度的气象输出正在成为超短期预测的重要气象输入源

## 4. 风电中长期功率/电量预测

### 4.1 45天中长期预测

45天中长期预测面向未来约一个半月的功率/电量预测，主要技术特点：

- **算法**：LightGBM回归器、SVM支持向量机、Lasso回归、Ridge回归、线性回归、弹性网络（ElasticNet）
- **聚类选站**：采用KMeans聚类算法，基于场站经纬度、断面信息进行聚类，利用轮廓系数（Silhouette Score）确定最优聚类数，从每个聚类簇中选取代表性场站
- **特征**：多气象源数据、赤纬角、太阳时角等天文特征
- **输出**：逐日/逐时段功率预测值

### 4.2 15个月月电量预测

15个月月电量预测面向未来一年以上的月度发电量预测，主要技术特点：

- **算法**：统计分析方法（statsmodels）、KMeans聚类、LightGBM
- **模型参数**：包含4个子模型系数和置信系数，通过标准配置文件管理
- **月度修正**：引入月度系数对各月预测结果进行季节性修正
- **数据标准化**：对训练数据进行标准化处理，确保不同量纲特征的可比性
- **输出**：逐月发电量预测值（MWh）

## 5. 风电概率预测

### 5.1 概述

概率预测为风电功率预测提供不确定性量化，不仅输出确定性预测值，还输出不同置信度下的功率预测区间（上界和下界）。随着电力市场化改革的深入，概率预测在风险评估、储能优化、市场报价决策中的作用日益凸显。

### 5.2 置信区间

概率预测覆盖的置信度包括：65%、70%、75%、80%、85%、90%等。

### 5.3 实现方法

- **分位数回归法**：对每个置信度训练上下界模型，分别预测该置信度下的功率上限和下限
- **分位数回归森林（Quantile Regression Forests）与分位数XGBoost**：这些方法能够直接输出预测区间，避免了独立建模带来的不一致性问题
- **聚类分组**：使用KMeans对场站进行聚类，不同分组分别建模
- **模型融合**：确定性预测与概率区间预测通过系数加权融合
- **输出格式**：每个预测时刻输出不同置信度对应的上限和下限功率值

**校准方法**：参见第一篇第11章《概率预测校准方法》（等渗回归、CRPS优化）。

## 6. 风电预测中的气象处理技术

### 6.1 多气象源融合

风电短期预测使用多种NWP数据源（EC、CMC、DWD、GFS、MF、GEFS、UKMO、JMA等），通过加权组合生成最优气象输入。最优权重编码通过遍历搜索和历史数据验证确定。

### 6.2 气象选点

采用两种方法为风电场选择最优NWP格点：

- **深度学习选点**：利用AI寻优算法自动搜索最优格点
- **统计相关性选点**：基于历史数据计算各格点与实发功率的相关性

### 6.3 气象订正

使用集合预报方法，结合人工智能寻优算法对NWP原始输出进行偏差订正。利用全国场站和气象站的长期观测数据构建订正模型。

### 6.4 AI降尺度技术

针对气象预报网格尺度过大（通常为数公里）无法精准对应场站的问题，基于AI的降尺度技术成为标配。通过三维神经网络适配地球坐标系统（如3D-EST技术），系统能将粗糙的气象要素“雕刻”到每个机位、每排组件的微观尺度。研究显示，AI技术对气象预报的改善贡献约20%，远超NWP模式切换带来的3–4%提升。（具体方法参见第一篇第4.3节）

### 6.5 风速系数优化

对每种气象源的风速数据，通过遍历搜索寻找最优系数k，使得“k×预报风速”与实际功率的平均绝对误差（MAE）最小。搜索范围从0.01到100，逐一计算每个k值对应的MAE，选取误差最小的k作为该气象源风速的最优修正系数。

## 7. 风电预测工程实践

### 7.1 系统架构

风电功率预测子站架构如下：

1. **气象服务器**（安全III区）：接收NWP数据，经反向隔离器传送至预测服务器
2. **预测服务器**（安全II区）：采集实发功率与实时气象数据，运行短期和超短期预测模型
3. **数据采集链路**：
   - 升压站数据：通过远动装置采集
   - 风机数据：通过风机监控平台采集
   - 测风塔数据：通过串口通信协议采集
4. **数据上传**：通过标准电力通信协议上传至调度主站

**2026年系统演进**：随着AI气象大模型的规模部署，电力监控系统安全防护架构面临新的挑战和优化空间。远景等企业正推动“气象大模型+电力系统”的深度融合，实现气象预测与功率预测在同一平台上的无缝衔接。

### 7.2 模型管理

- **模型训练周期**：使用约13个月历史数据进行训练
- **模型更新**：每3个月在线修订，修正精度
- **模型存储**：将训练好的模型序列化保存，便于加载推理
- **配置管理**：通过标准配置文件管理算法参数，支持参数的灵活调整

### 7.3 精度提升策略

1. **异常数据过滤**：过滤限电时段、设备故障等异常数据
2. **功率平滑**：使用Savitzky-Golay滤波器消除功率突变噪声
3. **在线自学习**：通过在线AI算法定期根据累积预测数据进行模型修订
4. **多模型集成**：多种算法模型预测结果加权融合
5. **专家干预**：增加专家人工干预接口，发挥人的经验和主观能动性

### 7.4 运维检查清单（风电特有）

参照第一篇第12章通用运维检查清单，风电增加以下专项检查：

- **每日**：测风塔各高度风速数据是否连续（无缺失超过1小时）
- **每周**：风速k系数是否需要重新校准（当MAE周环比上升>5%时触发）
- **每月**：气象选点是否需重搜索（季节变化或场站周围地形改变后）
- **每季度**：风功率曲线是否因叶片老化、桨距角漂移而变化，必要时重新拟合

### 7.5 故障处理案例（风电）

| 故障现象                                 | 应急处理                               | 根本解决                           |
| ---------------------------------------- | -------------------------------------- | ---------------------------------- |
| 测风塔多层风速不一致（如70m风速低于30m） | 采用可信层数据，其他层用风切变指数推算 | 增加冗余传感器，定期校准           |
| NWP风速系统性偏低（BIAS持续>0.2m/s）     | 临时提高风速系数k（+10%），触发重校准  | 部署在线学习k值的自适应算法        |
| 极端大风导致风机全部停机                 | 将预测功率强制设为0，并通知调度        | 增加基于集合预报的停机概率预警模块 |

## 8. 极端天气下的风电预测增强

极端天气（台风、暴雪、覆冰、低温结冰等）对风电功率预测造成显著挑战。第一篇第10章已系统阐述了台风、积雪/覆冰、低温结冰等场景的预测增强方法，包括集合预报加权、AI气象大模型台风路径产品、风速-停机概率模型、积雪光学衰减模型、结冰停机分类器等。针对风电特有的低温结冰问题，建议补充以下操作要点：

- 当**温度 < 0°C 且相对湿度 > 85%** 时触发结冰预警，基于历史SCADA数据训练随机森林/XGBoost分类器预测停机概率
- 结冰时段功率预测值乘以（1 - 预测停机比例）
- 对于极端事件小样本，采用迁移学习（从相似气候区电站迁移）或GAN合成样本

详细方法参见第一篇第10章《极端天气场景预测增强方法》。

## 9. 风电预测方法总结

| 预测类型   | 时间尺度              | 核心算法                                                     | 气象输入                      | 典型应用       |
| ---------- | --------------------- | ------------------------------------------------------------ | ----------------------------- | -------------- |
| 短期预测   | 0~72h（可延至7~10天） | XGBoost/LightGBM/CatBoost/LSTM/GRU/TCN/Transformer/GCN/CNN-LSTM系列 | 8种NWP日前气象+AI大模型增强   | 日前计划、调峰 |
| 超短期预测 | 0~4h（可延至10h）     | ARMA+LSTM/逻辑回归/CNN-BiLSTM                                | 日内NWP+测风塔实时+AI气象实时 | 实时调度、修正 |
| 45天中长期 | 45天                  | LightGBM/Lasso/Ridge/ElasticNet/SVM                          | 多气象源+ERA5                 | 电力平衡       |
| 月电量     | 15个月                | LightGBM/统计方法/KMeans                                     | 多气象源+ERA5                 | 中长期交易     |
| 概率预测   | 与短期一致            | 分位数回归/分位数回归森林/KMeans                             | 多气象源                      | 风险量化       |

**前沿方向**：

- **PINN（物理信息神经网络）**：2025-2026年，PINN技术成为风电预测的新前沿方向。研究表明，PINN通过将物理约束嵌入学习过程，在极端低温条件下的短期预测、基于SCADA数据的无NWP预测、以及风电功率概率不确定性量化等方面展现出显著优势。多篇研究探讨了扩散方程引导的物理融合、物理信息时空网络等新方法，标志着风电预测正从“纯数据驱动”向“物理-数据混合驱动”范式演进。
- **时间序列基础模型（TSFM）**：2026年对多种先进Transformer架构和时间序列基础模型在电力系统预测中的实证基准测试表明，基础模型正在成为风/光/荷预测的前沿方向，值得持续关注。

**偏差考核动态**：进入2026年，以福建、山东为代表的“两个细则”修订版已正式执行，加大了曲线偏差考核力度，增加了考核内容，优化了免考核信息披露机制。西北区域新能源场站“两个细则”也已全面落地，场站运行进入考核量化、收益挂钩、技术硬达标的全新阶段。官方信息显示，2025年6月浙江各场站因风光发电功率预测偏差发生的考核费用达250万元，单个场站考核费用最高超过20万元。
