# 任务和主题

AI新能源功率预报：根据历史发电功率数据和对应时段多类别气象预测数据，实现次日零时起到未来24小时逐15分钟级新能源场站发电功率预测。

# 比赛数据

1.**气象数据**
比赛输入数据来自三个不同的气象预报数据，数据格式为nc,共8个变量，需要注意气象源NWP_2的变量与另外两个稍有不同。气象变量说明见下文。每个文件是第二天北京时间0点开始的未来24小时气象预报，时间间隔1小时，文件名的日期表示预报发布日期，如20240101.nc是2024年1月1日发布的，对1月2日的预报。每个输入文件有5个维度，time,channel,hour,lat,lon。
time表示数据第一个时刻，为世界时；channel为变量，共8维；hour为从起始时间到预报时间的时间间隔，数值为0～23；lat为纬度，数值从小到大为从北向南排列；lon为经度，数值从小到大为从西向东排列。这里经纬度数值仅代表相对关系，中心点为离场站最近的点。
参赛队伍可以不使用全部气象源的全部变量做为输入。

2.**场站实发功率**
比赛目标数据来自10个新能源场站的归一化处理后的实发功率，其中包含5个风电场站和5个光伏场站。编号1-5为风电场，6-10为光伏电场。数据时间为北京时间，数据时间间隔为15分钟。需要注意数据中偶有空值、死值等异常值。

气象变量说明：

气象源1(NWP_1)、气象源3(NWP_3): [`u100`, `v100`, `t2m`, `tp`, `tcc`, `sp`, `poai`, `ghi`], 气象源2(NWP_2): [`u100`, `v100`, `t2m`, `tp`, `tcc`,`msl`,`poai`,`ghi`]

| **变量** | **描述**        | **单位**          |
| -------- | --------------- | ----------------- |
| `u100`   | 100米高度纬向风 | m/s（米/秒）      |
| `v100`   | 100米高度经向风 | m/s（米/秒）      |
| `t2m`    | 2米气温         | K（开尔文）       |
| `tp`     | 总降水量        | m（米）           |
| `tcc`    | 总云量          | (0 - 1)           |
| `sp`     | 地面气压        | Pa（帕斯卡）      |
| `poai`   | 光伏面板辐照度  | W/m²（瓦/平方米） |
| `ghi`    | 水平面总辐照度  | W/m²（瓦/平方米） |
| `msl`    | 海平面气压      | Pa（帕斯卡）      |

# 赛题类问题

Q：气象数据是不是少了20241231.nc？文件只到1230，有365个文件，而2024有366天，且factdata里面数据是366天的。
A：如比赛数据描述中提到的，每个文件是第二天北京时间0点开始的未来24小时气象预报，1230的数据是对1231的预报。本次比赛数据是从对2024年1月2日的预报数据开始的。可以理解为少了20240101的天气数据，但功率里面有20240101。

Q：场站周边 11x11 个格点的意思是，选取一个相对位置，然后从中心往外11个格点吗？
A：5是中心位置，0～4，6～10在两边，中间是距离场站最近的格点。

Q：功率有负值，也属于异常值吗？
A：绝对值比较小的负值可以在训练时置零。

Q：初赛训练集中气象数据1-10是什么意思？
A：1-5是风电场站，6-10是光伏场站。每个站场都有对应的气象预报。

Q：上传出现“Error bad input file”怎么办？
A：官网提供了提测示例文件output.zip，可以下载查看正确提交格式。需要注意文件夹的命名、文件的命名、文件内部结构需要和示例文件保持一致。

**关键词**：新能源功率预测，多源气象数据，机器学习融合，时序特征工程，CatBoost，LightGBM

## 1. 引言

### 1.1 项目背景与意义

随着全球能源转型加速，新能源发电在电力系统中的占比持续提高。根据国际能源署（IEA）报告，可再生能源将在未来十年内成为全球最大的电力来源。然而，风能和太阳能固有的间歇性和波动性给电网调度和稳定运行带来了巨大挑战。准确的功率预测成为解决这一问题的关键技术手段，对于提高新能源消纳能力、保障电网安全稳定运行具有重要意义。

### 1.2 技术挑战分析

新能源发电功率预测面临多重技术挑战：

**数据复杂性挑战**：

- 气象数据多源异构：来自三个不同气象源（NWP_1、NWP_2、NWP_3）的数据格式和变量定义存在差异
- 时空分辨率不匹配：气象数据为1小时间隔，而预测需求为15分钟级精度
- 异常值处理：功率数据中存在负值、缺失值和恒定值等异常情况

**预测精度挑战**：

#### 3.2.2 自定义损失函数设计

针对竞赛评价指标特点，设计了自定义损失函数：

```python
def custom_loss_squared_lgb(y_pred, train_data):
    """自定义损失函数 - 针对相对误差优化"""
    y_true = train_data.label
    
    # 分母处理：避免分母过小
    denominator = np.maximum(y_true, 0.2)
    error = (y_true - y_pred) / denominator
    
    # 梯度计算
    grad = -2 * error / (denominator ** 2)
    hess = 2 / (denominator ** 2)
    
    return grad, hess

def mae_metric_lgb(preds, train_data):
    """配套评估指标"""
    y_true = train_data.get_label()
    ty = np.maximum(y_true, 0.2)
    err = np.abs(preds - y_true) / ty
    return 'scaled_mae', np.mean(err), False
```

**创新点分析**：

- **分母保护机制**：通过分母最大值保护，避免低功率场景下的数值不稳定问题
- **相对误差优化**：损失函数设计与评价指标一致，直接优化预测精度
- **二阶导数优化**：提供准确的海森矩阵，加速模型收敛

```python
def cross_validation_training(model_class, train_x, train_y, test_x, params, n_splits=5):
    """交叉验证训练函数"""
    kf = KFold(n_splits=n_splits, shuffle=True, random_state=2024)
    test_predictions = np.zeros(test_x.shape[0])
    
    for i, (train_index, valid_index) in enumerate(kf.split(train_x, train_y)):
        print(f"Fold {i+1}/{n_splits}")
        
        # 数据分割
        trn_x, trn_y = train_x.iloc[train_index], train_y[train_index]
        val_x, val_y = train_x.iloc[valid_index], train_y[valid_index]
        
        # 模型训练
        model = model_class(**params)
        model.fit(trn_x, trn_y, eval_set=[(val_x, val_y)], 
                 early_stopping_rounds=66, verbose=False)
        
        # 预测融合
        test_pred = model.predict(test_x)
        test_predictions += test_pred / n_splits
    
    return test_predictions
```

```python
        self.validation_results = {}

        """运行交叉验证"""
        kf = KFold(n_splits=self.n_splits, shuffle=True, random_state=2024)
        fold_scores = []
        
        for fold, (train_idx, val_idx) in enumerate(kf.split(features)):
            print(f"Fold {fold+1}/{self.n_splits}")
            
            # 训练和验证
            train_features, train_target = features.iloc[train_idx], target[train_idx]
            val_features, val_target = features.iloc[val_idx], target[val_idx]
            
            model.fit(train_features, train_target)
            predictions = model.predict(val_features)
            
            # 计算得分
            score = self.calculate_score(val_target, predictions)
            fold_scores.append(score)
            
            self.validation_results[f'fold_{fold+1}'] = {
                'score': score,
                'predictions': predictions,
                'actual': val_target
            }
        
        return fold_scores
```
