## 1. 新能源发电基础概念

### 1.1 新能源（New Energy / Renewable Energy）
新能源指传统化石能源之外的可再生能源，电力领域主要指风能、太阳能。  
**截至2025年底**，中国风电、太阳能装机容量突破18.4亿千瓦（光伏12.0亿千瓦，风电6.4亿千瓦），占全国电源总装机的47.3%，首次超过火电成为第一大电源（国家能源局《2025年可再生能源并网运行情况》）。2025年风光发电量合计约2.3万亿千瓦时，占全社会用电量的22%。

### 1.2 风力发电（Wind Power Generation）
利用风能驱动风轮旋转，将动能转化为电能。风电场由多台风力发电机组（风机）组成，经升压站并网。风机运行状态：运行、检修、故障、待机、离线、限电、正常停机、大风停机、无风停机。

### 1.3 光伏发电（Photovoltaic Power Generation）
利用半导体光生伏特效应将太阳辐射能直接转化为电能。光伏电站由组件（电池板）、逆变器、升压站组成。逆变器运行状态：运行、正常停机、待机、故障、通讯中断。

### 1.4 集中式电站（Centralized Power Station）
大容量（数十MW至数百MW）、集中连片开发，直接接入输电网（≥35kV），具备完整的测风/测光、功率预测和数据采集系统。

### 1.5 分布式电源（Distributed Generation, DG）
分布在用户侧、规模小（kW~数MW），数量多、分布广。分布式光伏最常见，接入电压等级通常为380V/220V或10kV。出力波动性大，对负荷预测、电力平衡影响日益增大。

## 2. 功率预测基础概念

### 2.1 功率预测（Power Prediction / Forecasting）
利用历史功率、气象、地形、数值天气预报（NWP）、设备状态等数据，建立预测模型，输出未来时段的输出功率。核心目的：辅助电网调度、提升消纳、支持现货市场报价、降低偏差考核成本。

### 2.2 短期预测（Short-term Prediction）
- **时间尺度**：未来0~72小时（可延至7~10天）
- **时间分辨率**：15分钟
- **用途**：日前发电计划、调峰、日前市场报价
- **技术路线**：以NWP为主，结合历史数据和多种机器学习模型（XGBoost/LightGBM等）

### 2.3 超短期预测（Ultra-short-term Prediction）
- **时间尺度**：未来0~4小时（可延至6~10小时）
- **时间分辨率**：15分钟，滚动预测
- **用途**：实时调度、日内修正、日内市场交易
- **技术路线**：基于实发功率数据 + 短期预测结果 + 日内NWP更新，常用ARMA+LSTM或SVM

### 2.4 中长期预测（Medium- and Long-term Prediction）
- **45天预测**：用于月度电力电量平衡及中长期交易策略制定
- **15个月月电量预测**：输出逐月发电量（MWh），用于年度/月度电力电量平衡、中长期交易、资源评估

### 2.5 概率预测（Probabilistic Prediction）
不仅给出确定性预测值，还输出不同置信度（60%~95%，共8个等级）下的功率预测区间（上界/下界）。用于量化不确定性、风险评估、鲁棒调度、市场报价优化。

## 3. 预测精度评价指标（统一符号与定义）

本文件统一以下符号：  
- \(P_{\text{act},i}\)：第 \(i\) 个时刻的实际功率（单位：MW 或标幺值）  
- \(P_{\text{pred},i}\)：第 \(i\) 个时刻的预测功率  
- \(Cap\)：电站装机容量（归一化基准）  
- \(n\)：样本数量

### 3.1 均方根误差准确率（RCR）

\[
RCR = \left(1 - \sqrt{\frac{1}{n}\sum_{i=1}^{n}\left(\frac{P_{\text{act},i} - P_{\text{pred},i}}{Cap}\right)^2}\right) \times 100\%
\]

### 3.2 改进型均方根误差准确率（\(C_R\)）

常见于部分电网考核细则（西北、华北），采用动态分母避免除零并加重低功率段惩罚：

\[
C_R = \left(1 - \sqrt{\frac{1}{n}\sum_{i=1}^{n}\left(\frac{P_{\text{act},i} - P_{\text{pred},i}}{\max(P_{\text{act},i}, \delta)}\right)^2}\right) \times 100\%
\]

其中 \(\delta\) 为小量常数，通常取装机容量的1%~2%（例如100MW电站取2MW）或固定值0.2MW（依各省细则）。意义：当实际功率很小时，分母强制为 \(\delta\)，使同样绝对偏差产生更大相对误差，引导模型关注低功率段精度。

### 3.3 平均绝对误差（MAE）

\[
MAE = \frac{1}{n} \sum_{i=1}^{n} |P_{\text{act},i} - P_{\text{pred},i}|
\]

### 3.4 绝对值误差准确率（ACR）

\[
ACR = \left(1 - \frac{\sum_{i=1}^{n} |P_{\text{act},i} - P_{\text{pred},i}|}{n \times Cap}\right) \times 100\%
\]

### 3.5 合格率（QR）
满足精度要求的预测点占总预测点数的百分比，合格标准由各省级调度考核细则确定。

### 3.6 概率预测专用指标
- **PICP（Prediction Interval Coverage Probability）**：实际值落在预测区间内的比例，应接近名义置信度。
- **PINAW（Prediction Interval Normalized Average Width）**：区间平均宽度归一化值，锐度越小越好。
- **CRPS（Continuous Ranked Probability Score）**：同时评估区间覆盖率和锐度的综合指标。
- **校准（Calibration）**：对分位数回归结果进行等渗回归（Isotonic Regression）或分位数校准，使实际覆盖率与名义置信度一致。

### 4.3 降尺度技术（Downscaling）
- **统计降尺度**：基于历史观测建立大尺度→站点映射
- **动力降尺度**：区域气候模式嵌套
- **AI降尺度**：三维神经网络学习映射，将NWP 25km格点“雕刻”到1km甚至机位级

### 4.4 多模态融合气象
将多种NWP源（EC、GFS、JMA等）通过权重自适应、误差互补、时空一致性约束融合，提升鲁棒性。权重可通过历史数据遍历搜索或在线学习确定。

## 5. 电力市场与偏差考核

### 5.1 电力市场概述
截至2025年底，中国市场化交易电量超6.6万亿千瓦时，占全社会用电量64%。主要交易品种：
- **中长期交易**：年度、月度、多月，压舱石
- **现货市场**：日前市场 + 日内/实时市场
- **辅助服务市场**：调频、调峰、备用

### 5.2 现货市场与功率预测的关系
- **日前市场**：基于短期功率预测申报次日发电量和价格
- **日内市场**：基于超短期预测滚动调整，减少偏差
- **省间现货**：2026年4月新版规则实施，日内交易频次提升1倍，交易周期缩短至1小时，新能源可高频参与

### 5.3 偏差考核（Deviation Penalty）
实际发电量与申报量的偏差超出免考核范围（通常±5%~±15%，如山东±5%、甘肃±10%、蒙西±15%）时，按偏差电量×偏差电价处罚。偏差考核与《并网运行管理实施细则》《辅助服务管理实施细则》（“两个细则”）挂钩。  
**实测数据**：2025年6月浙江各场站风光功率预测偏差考核费用达250万元，单个场站最高超20万元。

### 5.4 电价预测
预测日前/日内/中长期电价，用于市场报价决策。核心影响因素：新能源出力水平、负荷需求、系统供需平衡、网络约束。功率预测是电价预测的关键输入之一。

## 6. 储能与虚拟电厂

### 6.1 储能（Energy Storage）
截至2025年底，全国新型储能装机1.36亿千瓦（+84%）。主要类型：电化学（锂电、液流、钠电）、机械（抽水蓄能、压缩空气）、电磁（超级电容）。

### 6.2 新能源配储政策
国家发改委、国家能源局《关于深化新能源上网电价市场化改革促进新能源高质量发展的通知》（发改价格〔2025〕136号）明确：2025年2月9日后批复的新能源项目不再强制要求配置储能，鼓励租赁独立储能容量。配储由经济性驱动（峰谷套利、减少偏差考核）。

### 6.3 储能与功率预测协同
- **日前调度**：基于短期预测+电价预测，优化次日充放电计划
- **日内修正**：基于超短期预测实时补偿功率偏差
- **能量管理**：基于中长期预测制定月度/年度策略

### 6.4 虚拟电厂（VPP）
聚合分布式电源、储能、可调负荷，统一参与市场交易。功率预测和储能管理是其两大核心能力。

## 7. 预测系统架构与工程实践

### 7.1 预测子站与主站
- **子站**（电站侧）：采集实发功率、实时气象，运行超短期模型，上传预测值
- **主站**（调度侧）：接收所有电站数据，进行区域/全网预测、精度评价、调度决策

### 7.2 数据通信规范
常见协议：IEC 104、Modbus TCP、MQTT over 5G。标准数据点表可参考 Q/GDW 1998-2022《新能源功率预测数据通信规范》。

### 7.3 安全隔离
反向隔离器用于从安全III区（信息管理区）向II区（控制区）单向传输气象数据。

### 7.4 样板电站与出力还原
- **样板电站**：在分布式区域按行政划分或地理信息聚类选出的代表性电站，用于推算区域总出力。
- **出力还原**：针对未安装采集设备的“黑点”电站，利用邻近样板数据通过线性/非线性回归或图神经网络（GCN/GAT）估计其出力。

## 8. 预测方法选型指南

根据业务需求选择预测方法：

```text
决策树流程：

1. 是否有高精度NWP输入？
   ├─ 否 → 仅使用历史数据和简单模型（持续法、ARIMA、LightGBM无NWP版）
   └─ 是 → 进入2

2. 时间尺度？
   ├─ 0~4h（超短期）
   │   ├─ 有实时测风/辐照仪？ → 是 → ARMA+LSTM 或 SVM
   │   └─ 否 → 持续法 + 滚动平均
   ├─ 0~72h（短期）
   │   ├─ 数据量 > 2年且计算资源充足 → XGBoost/LightGBM + 多源NWP融合
   │   ├─ 需要极致精度 → 集成学习（Stacking）或 Transformer变体
   │   └─ 分布式无NWP → 样板站映射 + 网格化气象
   ├─ 45天 ~ 15个月（中长期）
   │   └─ LightGBM / Lasso / Ridge + ERA5再分析数据 + 天文特征
   └─ 概率预测需求？
       ├─ 是 → 分位数回归 / 分位数回归森林 / 分位数XGBoost
       └─ 否 → 确定性预测

3. 是否面临极端天气（台风、暴雪、覆冰）？
   └─ 是 → 采用集合预报加权 + 极端事件迁移学习 + 停机概率模型
```

## 9. 预测误差诊断流程

当预测偏差超标时，按以下步骤定位问题：

1. **计算BIAS（系统性偏差）**  
   \[
   BIAS = \frac{1}{n}\sum (P_{\text{pred},i} - P_{\text{act},i})
   \]
   - 若BIAS > 0（长期偏大） → 检查NWP风速/辐照度是否偏高，或模型截距项过大  
   - 若BIAS < 0（长期偏小） → 检查NWP是否偏低，或限电数据是否误剔除

2. **分时段误差分析**  
   - 夜间/弱风段误差大 → 改进低功率段特征（增加开关机逻辑、平滑处理）  
   - 午后光伏误差大 → 检查温度对组件效率的修正、云量预测

3. **分天气类型分析**  
   - 阴雨天误差大 → 补充云量、降水、辐射衰减特征；使用集合预报  
   - 晴天误差大 → 检查天文辐射计算是否正确、辐照度-功率映射是否线性

4. **分季节分析**  
   - 冬季风电误差大 → 考虑叶片结冰停机概率模型  
   - 夏季光伏误差大 → 增加高温降额修正

5. **模型过拟合检查**  
   - 训练集精度高但验证集低 → 减少树深度、增加正则化、增加dropout

6. **数据质量问题**  
   - 检查NWP是否准时到达（超时>30分钟）  
   - 检查测风塔/辐照仪是否存在死值、跳变（用3σ或孤立森林检测）

## 10. 极端天气场景预测增强方法

### 10.1 台风
- 使用集合预报（ENS/GEFS）中各成员的路径和风速，加权融合（权重根据历史路径误差动态分配）
- 结合AI气象大模型（盘古、风乌）的台风路径产品
- 建立风速-停机概率模型（当风速 > 切出风速时停机概率陡增）

### 10.2 光伏组件积雪/覆冰
- 引入积雪深度预报（来自NWP或气象大模型）
- 建立光学衰减模型：积雪覆盖导致透光率下降，衰减系数与积雪厚度呈指数关系
- 覆冰时增加停机概率（逆变器保护）

### 10.3 低温导致风机叶片结冰
- 当温度 < 0°C 且湿度 > 85% 时触发结冰预警
- 基于历史结冰事件的SCADA数据训练停机预测分类器（随机森林或XGBoost）
- 结冰时段功率预测乘以（1 - 预测停机比例）

### 10.4 小样本学习策略
- 极端事件历史样本少，采用迁移学习（从相似气候区电站迁移）或生成对抗网络（GAN）合成样本

## 11. 概率预测校准方法

### 11.1 分位数回归的不一致问题
分位数回归直接输出各分位数（如0.1, 0.5, 0.9），但实际覆盖率可能偏离名义置信度。需要后处理校准。

### 11.2 等渗回归（Isotonic Regression）校准
- 步骤：在验证集上，对每个分位数预测值 \(q\) 计算实际累积分布函数值 \(p_{\text{emp}}(q)\)
- 学习单调映射 \(q' = f(q)\)，使得 \(p_{\text{emp}}(q') \approx \text{目标分位数}\)
- 应用：用 \(f\) 变换新预测的分位数，得到校准后的预测区间。

### 11.3 基于CRPS的集成校准
- 使用多个分位数模型的预测，通过最小化CRPS学习最优组合权重。

### 11.4 面向现货市场报价的最优分位数选择
- 定义损失函数：报价偏高导致未中标损失，报价偏低导致收益减少
- 求解最优分位数 \(\tau^*\) 使期望收益最大化（通常 \(\tau^* > 0.5\) 表示风险规避）

## 12. 预测系统运维检查清单

### 12.1 每日检查
- [ ] NWP数据是否在凌晨 4:00 前到达（含所有气象源）？
- [ ] 所有模型推理是否成功（日志无ERROR）？
- [ ] 超短期模型每15分钟滚动运行，上传调度是否超时（< 5秒）？
- [ ] 实际功率采集是否连续（无断点超过2小时）？

### 12.2 每周检查
- [ ] 重跑最近一周的预测精度（RCR, MAE），与上周对比，偏差 > 5% 则报警
- [ ] 检查测风塔/辐照仪数据是否有跳变（与邻近电站对比）

### 12.3 每月检查
- [ ] 评估是否触发模型重训练条件（精度下降 > 3% 或距离上次训练 > 3个月）

- [ ] 重新校准风速系数（k 值）和辐照度修正系数

### 12.4 每季度检查
- [ ] 更新极端天气事件样本库
- [ ] 评估概率预测的PICP和PINAW，必要时重新校准分位数

### 12.5 故障处理案例库（部分）
| 故障现象                         | 应急处理                                                     | 根本解决                               |
| -------------------------------- | ------------------------------------------------------------ | -------------------------------------- |
| NWP长时间未更新（> 6小时）       | 切换到备选气象源（如GFS替代EC），或使用持续法+ARMA自回归     | 建立冗余气象源自动切换机制             |
| 测风塔数据跳变（风速突变>15m/s） | 采用3σ异常检测，剔除异常值，用邻近电站风速插值               | 增加传感器冗余，部署实时异常检测模型   |
| 模型在线预测耗时 > 15分钟        | 降采样特征（减少滞前滞后特征），或换用LightGBM替代Transformer | 优化特征缓存，升级推理硬件或模型轻量化 |
| 上传调度主站超时                 | 本地缓存预测结果，网络恢复后补传                             | 配置双通道通信（4G+光纤）              |

## 13. 负荷预测

### 13.1 负荷预测定义
负荷预测（Load Forecasting）指基于历史负荷数据、气象条件、日期类型（工作日/节假日）、经济活动等影响因素，预测未来一定时间尺度内的电力系统有功负荷（单位：MW）。负荷预测是电网调度、发电计划、电力市场交易、输变电设备运维的基础依据。

### 13.2 负荷预测与新能源预测的关系
- 新能源出力占比持续提升，净负荷（系统负荷 − 新能源出力）波动加剧，负荷预测需与新能源预测协同使用。
- **净负荷预测**：直接预测系统负荷减去新能源出力后的剩余负荷，用于常规机组开机组合。
- 两者共享部分气象特征（温度、湿度、云量），但负荷对温度敏感，新能源对辐照/风速敏感。

### 13.3 负荷预测时间尺度

| 类型           | 时间范围       | 时间分辨率   | 主要用途                             |
| -------------- | -------------- | ------------ | ------------------------------------ |
| 超短期负荷预测 | 未来0~4小时    | 15分钟/5分钟 | 实时调度、AGC、自动发电控制          |
| 短期负荷预测   | 未来24小时~7天 | 1小时/15分钟 | 日前发电计划、日前市场、旋转备用安排 |
| 中期负荷预测   | 未来1个月~1年  | 日/周/月     | 月度电量平衡、检修计划、燃料采购     |
| 长期负荷预测   | 未来1~10年     | 年           | 电网规划、电源建设、投资决策         |

### 13.4 负荷预测常用评价指标

除第3节定义的MAE、RMSE外，负荷预测领域常用以下指标（设 \(L_{\text{act},i}\) 为实际负荷，\(L_{\text{pred},i}\) 为预测负荷）：

#### 13.4.1 平均绝对百分比误差（MAPE）

\[
MAPE = \frac{1}{n} \sum_{i=1}^{n} \left| \frac{L_{\text{act},i} - L_{\text{pred},i}}{L_{\text{act},i}} \right| \times 100\%
\]

*注：当实际负荷接近0时（极端小负荷时段），MAPE可能失真，此时改用MAE。*

#### 13.4.2 加权平均绝对百分比误差（WMAPE）

\[
WMAPE = \frac{\sum_{i=1}^{n} |L_{\text{act},i} - L_{\text{pred},i}|}{\sum_{i=1}^{n} L_{\text{act},i}} \times 100\%
\]

避免分母为零，且反映大负荷时段占主导的误差权重。

#### 13.4.3 峰值负荷误差

\[
PeakError = \frac{|L_{\text{act,peak}} - L_{\text{pred,peak}}|}{L_{\text{act,peak}}} \times 100\%
\]

用于评估电网高峰时段的预测能力，对调度可靠性至关重要。

### 13.5 负荷预测影响因素

| 类别         | 具体因素                                                     | 建模处理方式                         |
| ------------ | ------------------------------------------------------------ | ------------------------------------ |
| 气象因素     | 温度（干球/湿球）、湿度、风速、云量、降水、日照时数          | 加入滞后温度特征（24h前温度、48h前） |
| 日期类型     | 工作日/周末、节假日（春节/国庆等）、调休、特殊活动（购物节） | 独热编码或周期性嵌入                 |
| 经济因素     | GDP、工业增加值、居民收入、电价水平                          | 中长期预测使用，短期可不考虑         |
| 社会行为     | 疫情/封控、极端天气导致居家、季节性作息（夏时制）            | 作为事件标签加入                     |
| 历史负荷模式 | 日周期性（24h）、周周期性（168h）、年周期性（8760h）         | 采用时间序列分解或注意力机制         |

### 13.6 负荷预测常用方法

#### 13.6.1 传统时间序列方法
- **ARIMA / SARIMA**：适用于平稳、周期性强且无剧烈气象波动的负荷序列。
- **指数平滑（Holt-Winters）**：处理趋势和季节分量，轻量高效。

#### 13.6.2 机器学习方法
- **XGBoost / LightGBM / CatBoost**：特征工程能力强，可融入日期、温度、滞后负荷等多维特征，短期负荷预测主流方案。
- **随机森林**：不易过拟合，适用于缺失值较多场景。

#### 13.6.3 深度学习方法
- **LSTM / GRU**：捕获负荷序列长短期依赖，对温度滞后效应建模良好。
- **Transformer / Informer**：处理超长序列（如7天小时级），具备多头注意力，适用于多变量输入。
- **TCN（时序卷积网络）**：并行计算优于RNN，感受野可控。

#### 13.6.4 集成与混合模型
- **Stacking**：将XGBoost、LSTM、SARIMA的预测结果作为元特征，输入元学习器（如岭回归）融合。
- **物理-数据混合**：结合热力学模型（建筑热惯性）修正纯数据驱动预测。

### 13.7 负荷预测典型流程

```text
数据采集
├── 历史负荷（SCADA）—— 缺失值填充（线性插值/邻近日替换）
├── 气象数据（NWP或站点观测）—— 温度、湿度、风速
└── 日历特征（日期类型、节假日）—— 自动生成

特征工程
├── 滞后特征：t-24, t-48, t-168
├── 滚动统计：过去6小时均值/方差
├── 温度编码：湿球温度、降温/升温速率、累积温度效应（CDD/HDD）
└── 周期性编码：sin/cos变换（小时、星期）

模型训练与验证
├── 训练集：过去1~3年，滚动窗口（避免数据泄露）
├── 验证方式：时序交叉验证（时间顺序切分，禁止随机打乱）
└── 超参数调优：Optuna / Bayes Search

预测与后处理
├── 输出各时间点负荷
├── 异常修正：当预测负荷超过历史最大值±20%时，限幅到合理区间
└── 概率预测：分位数回归森林 / 分位数XGBoost
```

### 13.8 负荷预测误差诊断要点

当负荷预测偏差超标时，优先排查：

1. **温度特征处理**：是否使用湿球温度而非干球？夏季高温饱和点时湿球温度更具解释力。
2. **节假日处理**：是否正确标注调休日（周日上班）和特殊假日（如地方性节日）？
3. **滞后阶数**：负荷对温度响应有热惯性，需加入过去24~48小时温度平均值。
4. **模型更新频率**：负荷模式随季节和用电结构变化，建议每周重训练一次。
5. **异常事件**：是否纳入突发工业限电、疫情封控等外部事件？

### 13.9 负荷预测与现货市场

- **日前负荷预测**：决定次日需开启的机组容量（开机组合）和备用容量。
- **实时负荷预测**：用于实时平衡市场出清，偏差导致调频费用增加。
- **节点边际电价（LMP）计算**：负荷分布是潮流计算的关键边界条件，负荷预测误差直接传导至电价预测偏差。

### 13.10 分布式负荷预测（配电网）

- 配电网侧负荷节点多、量测不全，常采用 **自下而上** 方法：
  - 典型用户曲线聚类（居民、商业、工业）
  - 通过智能电表数据（15分钟级）建立用户级模型，累加得到台区/馈线负荷。
- **非侵入式负荷监测（NILM）**：从总负荷中分解出空调、热水器等主要设备功耗，提升细分预测能力。

## 附录B：低成本方案建议（适用于小型分布式电站）

若电站无NWP、无测光塔、历史数据不足1年，可采用：
- **持续法（Persistence）**：未来15分钟功率 ≈ 当前功率（超短期可用）
- **免费气象数据**：NASA POWER（全球）、ERA5（再分析，有15天滞后）
- **邻近电站分享模型**：通过联邦学习框架，聚合多个小型电站数据训练一个共享模型，每个电站只上传模型梯度而非原始数据。
- **简单时间序列分解**：STL（季节性+趋势分解）+ 线性回归，仅用历史功率和日期特征。
